The 10 architecture points

Explanation of each numbered block in the reference diagram.

  1. 1

    Data Sources

    Starting point: corporate systems (ERP, WMS, CRM, Finance, HR), operational databases (Oracle, SQL Server, SingleStore, SAP), files and documents (SharePoint, SFTP, Excel, CSV, JSON), external sources and APIs (REST, ArcGIS, Survey123, web), and federation to Oracle DWH / Azure Synapse via Lakehouse Federation.

  2. 2

    Azure Databricks (core platform)

    Main container where data engineering, governance, and AI happen. It groups ingestion, processing, Unity Catalog / AI Gateway, Medallion layers, serve, and transversal security.

  3. 3

    Ingestion

    Bringing data into the lakehouse with Databricks Ingestion (Auto Loader, Jobs, Notebooks), REST API endpoints, connectors (Oracle, SAP, SharePoint), and Event Hubs / Azure Data Factory for streaming and batch.

  4. 4

    Processing (Pipelines & Orchestration)

    Transformation and modeling engine: Workflows & Jobs ETL/ELT, Notebooks (PySpark, SQL, Python, R), Delta Live Tables, AutoML / MLflow, and Data Science & GenAI (RAG, features, embeddings, vector search).

  5. 5

    Governance & Data (Unity Catalog + AI Gateway)

    Data governance with catalogs, schemas, tables, volumes, lineage, permissions, quality, and RLS/CLS. AI governance with models, endpoints, agents, guardrails, and traceability. Medallion flow: Bronze (Raw) → Silver (Clean) → Gold (Outputs) → Consumption.

  6. 6

    Serve / Output

    Delivery layer for the business: Power BI, Databricks Apps, Agents, and Apps / APIs for external or embedded consumption.

  7. 7

    End User

    Who consumes the value: business users (Q&A, reports, decisions), analysts (exploration and self-service), corporate areas (Sales, HR, Finance, Supply Chain), and human-in-the-loop processes with approval and control.

  8. 8

    Transversal Security & Governance

    Horizontal layer inside Databricks: Microsoft Entra ID (SSO/MFA), RLS/CLS, secrets and credentials with Azure Key Vault, end-to-end audit and lineage, and network security (Private Link, VNets, NSGs, IP whitelisting).

  9. 9

    Monitoring & Operations (Azure)

    Services outside Databricks that sustain operations: Azure Monitor, Log Analytics, Azure DevOps (CI/CD), alerts (Email/Teams/SMS), Cost Management, Backups & DR, Azure Policy / Defender, and audit.

  10. 10

    Architectural Principles

    Design guides: Security by Design (Zero Trust and least privilege), Data Governance, serverless/elastic Scalability, Observability, Responsible AI (guardrails and evaluations), and Business Value with reliable data for decisions.
